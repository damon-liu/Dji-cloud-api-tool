# DJI Cloud API 监控客户端 — 小白也能看懂的使用指南

## 一、这是什么？

本工具通过 MQTT 协议连接 DJI Cloud API，实时接收并展示机场和无人机的Topic数据，主要用于日常对接调试大疆上云API（第三方机场如果提供类似大疆上云API也可使用），是大疆行业设备开发者和运维人员的必备调试工具。

### 核心功能

- **MQTT 连接管理** — 支持 SSL/TLS 加密连接，可配置 Broker 地址、端口、用户名和密码，连接状态实时显示在底部状态栏；
- **多环境配置切换** — 支持多个 Connection（连接配置），每个 Connection 拥有独立的 MQTT 参数和设备列表，一键切换生产/测试环境，互不干扰；
- **设备树形管理** — 树形展示机场 + 无人机设备的层级关系，支持新增/删除/重命名设备，在线状态实时指示等
- **OSD 遥测面板** — 机场数据和飞机数据实时刷新；
- **JSON 字段自动翻译** — 将 DJI JSON 报文中的英文字段自动翻译为中文，字段意义一目了然；
- **原始 JSON 面板** — 按选中订阅 Topic 过滤 MQTT 原始报文，支持暂停滚动、一键复制全部内容和清除历史记录；
- **Topic 订阅管理** — 对每个设备独立管理 Topic 列表，支持新增/删除/启用/禁用/拖拽排序，添加机场时自动创建常用 Topic，省去手动配置 Topic 工作；
- **抓包导出** — 将接收到的 MQTT 数据实时写入 `captures/` 文件夹，支持随时开始/停止，停止后弹窗显示文件路径和记录条数；
- **自动重连** — MQTT 意外断开后指数退避自动重连（1s → 2s → 4s → 8s → 最长 30s），重连成功后自动恢复数据刷新；
- **刷新间隔可配** — OSD 面板和 JSON 解析面板刷新间隔均可独立调节（1s / 2s / 5s / 10s），适应不同网络环境和数据量；
- **断线保护** — 断开连接时自动暂停面板刷新，避免无效重绘；手动暂停优先级高于自动恢复，防止打断数据查看；
- **免安装绿色运行** — 下载即用，无需安装 Qt 或其他任何依赖，Windows 10/11 x64 直接运行；

## 二、与 MQTTX 工具调试的优点

很多开发者使用 [MQTTX](https://mqttx.app/) 进行 MQTT 调试，但针对 DJI Cloud API 场景，本工具有以下明显优势：

| 对比维度 | MQTTX | DjiCloudApiTool |
|----------|-------|-----------------|
| 设备识别 | 只能看到 Topic 字符串，需人工判断是哪个设备 | 自动识别设备 SN，树形展示机场与子飞机的层级关系 |
| 数据可读性 | 原始 JSON，字段名全英文（如 `cabin_opened`、`drone_in_dock`） | 自动翻译为中文，分组展示，一目了然 |
| 多设备管理 | 所有 Topic 混在一起，无层级结构 | 每个设备独立管理 Topic，支持启用/禁用/拖拽排序 |
| 抓包导出 | 需手动复制粘贴或配置外部工具 | 一键抓包，自动按设备和 Topic 分类保存到 `captures/` 文件夹 |
| 配置切换 | 每次切换服务器需手动修改连接参数 | 多 Connection 配置，一键切换生产/测试环境 |
| 断线处理 | 需手动重连 | 自动重连 + 指数退避，恢复后自动刷新数据 |
| JSON 字段定位 | 需在长 JSON 中肉眼查找字段 | 点击翻译面板中的字段名直接复制原始 key，精准定位 |
| 环境依赖 | 需安装 Node.js 或下载桌面版 | 单文件 exe，无需任何依赖 |
| 学习成本 | 通用 MQTT 工具，需自行理解 DJI 协议 | 专为 DJI Cloud API 设计，开箱即用 |

> 💡 总结：MQTTX 是优秀的通用 MQTT 调试利器，但 DjiCloudApiTool 在 DJI 行业设备场景下效率更高——**自动翻译、设备层级树、抓包导出、多环境一键切换**等功能都是针对大疆设备的专属优化。

## 四、第一步：连接 MQTT 服务器

打开软件后，先连上你的 MQTT Broker（这是数据来源）：

### ① 点击左上角「⚙ 配置」按钮

会弹出一个配置窗口：

![image-20260710113140164](C:\Users\lhx\AppData\Roaming\Typora\typora-user-images\image-20260710113140164.png)

### ② 填写参数

| 参数 | 说明 | 示例 |
|------|------|------|
| Broker IP | MQTT 服务器地址 | 192.168.1.100 |
| 端口 | 一般是 8883 | 8883 |
| 用户名 | MQTT 用户名 | admin |
| 密码 | MQTT 密码 | 你的密码 |

### ③ 点「Test」测试连接

> ⚠️ 如果提示"连接失败请检查配置参数是否有误"，请确认 IP、端口、用户名、密码无误。

### ④ 测试通过后，点「OK」保存

## 五、第二步：添加设备

连上服务器后，还需要告诉软件你要监控哪些设备。

![image-20260710144659826](C:\Users\lhx\AppData\Roaming\Typora\typora-user-images\image-20260710144659826.png)

### ① 点击左侧「＋」按钮

### ② 选择设备类型

- **Dock (机场)**：大疆机场/机库设备
- **Pilot (手飞飞机)**：无人机

### ③ 输入设备 SN 和设备名称

> 💡 SN 就是设备的序列号，在设备机身标签上能找到。

### ④ 点击确定

添加机场设备时，**软件会自动创建关联的无人机设备**，不用手动再添加。

添加完设备后，左侧会显示设备列表：

- 🟢 绿色 = 设备在线
- 🔴 红色 = 设备离线

### 设备列表操作

| 操作 | 方式 |
|------|------|
| 选中设备 | 单击设备行 |
| 复制设备 SN | 双击设备行 |
| 重命名设备 | 右键设备 → 重命名 |
| 添加子设备 | 选中机场 → 点「＋」→ 为机场添加手飞无人机 |
| 删除设备 | 选中设备 → 点「✕」 |

## 七、界面功能详解

### 📡 OSD 实时面板（右上区域）

默认 **1 秒刷新一次**，可以手动调整（1s / 2s / 5s / 10s）。

| 字段 | 含义 |
|------|------|

| 舱内温度 | 机库内部温度 |
| 环境温度 | 室外温度 |
| 风速 | 当前风速 |
| 降雨量 | 当前降雨量 |

#### 飞机信息（与机场并排显示）

| 字段 | 含义 |
|------|------|
| 飞行状态 | 待机 / 起飞 / 航线飞行 / 返航 / 降落 |
| 经纬度 | 飞机当前 GPS 坐标 |
| 电量 | 电池剩余百分比 |
| 电池温度 | 电池温度 |
| 高度 | 相对起飞点高度 |
| 距Home | 距起飞点距离 |
| 风速 | 当前风速 |

### 🔍 JSON 解析面板（OSD 面板下方）

把原始 JSON 数据翻译成中文，方便阅读。

- 📌 **点击左侧 Topic 切换**，显示对应 Topic 的解析数据

- ⏱ 刷新间隔可调（默认 2 秒，可选 1s/2s/5s/10s）

- 📦 数据按分组展示（基础信息、电源、飞行、定位、环境等），一目了然

### 🗂 原始 JSON 面板（右侧）

显示 MQTT 原始报文，适合技术人员查看。

每条数据包含：
```

[time] 2026-07-10 14:30:25
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

操作按钮：

| 按钮 | 功能 |
|------|------|
| ⬤ 抓包 | 开始/停止导出数据到文件 |
| ⏸ 暂停 | 冻结界面显示，但数据仍在后台接收，恢复后一次性补齐 |
| 📋 复制 | 复制当前窗口全部 JSON 内容 |
| 🗑 清除 | 清空当前显示的历史记录 |

### 📦 抓包导出（重点功能）

**作用：把接收到的数据保存到文件，方便事后分析。**

![image-20260710145357858](C:\Users\lhx\AppData\Roaming\Typora\typora-user-images\image-20260710145357858.png)

操作步骤：
1. 点击 **「⬤ 抓包」** 按钮
2. 数据实时写入 `captures/` 文件夹
3. 点击 **「⏹ 停止」** 结束抓包
4. 弹窗显示文件路径和记录条数
5. 点击 **「打开文件夹」** 直接定位到文件

文件命名规则：`设备SN-topic类型-时间.json`

文件格式：
```json
[
{"tid":"...","timestamp":...,"data":{...}},
{"tid":"...","timestamp":...,"data":{...}}
]
```

### 📋 Topic 管理（左侧下方）

![image-20260710144918526](C:\Users\lhx\AppData\Roaming\Typora\typora-user-images\image-20260710144918526.png)

选中设备后，下方显示该设备订阅的所有 Topic：

```
Topic 列表          [＋] [◎] [✕] [▲] [▼] [⊘]
────────────────────────────────────────
● thing/product/dock001/osd
○ thing/product/dock001/state
● thing/product/drone001/osd
```

| 按钮 | 功能 |
|------|------|
| ＋ | 新增自定义 Topic |
| ◎ | 启用/禁用当前选中的 Topic |
| ✕ | 删除选中的 Topic |
| ▲▼ | 上下移动调整 Topic 顺序 |

- **● 实心** = 已启用（正在接收数据）
- **○ 空心** = 已禁用（暂停接收）
- **双击 Topic** → 复制完整 Topic 字符串

> 💡 添加机场设备时，软件会自动添加 7 个常用 Topic（默认禁用状态），需要的时候手动启用即可。这些默认 Topic 包括 state、requests、events、services_reply、property/set_reply、status、drc/up。

## 八、实用小技巧

### 🖱 快捷操作汇总

| 操作 | 方式 |
|------|------|
| 复制设备 SN | 双击设备列表中的设备 |
| 复制 Topic | 双击 Topic 列表中的 Topic |
| 复制 JSON Key | 点击解析面板中的字段名 |
| 重命名设备 | 右键设备 → 重命名 |

### 🔄 断线自动重连

MQTT 意外断开时：
- 软件会自动尝试重连（首次等待 1 秒，逐次翻倍，最长 30 秒）
- OSD 面板和 JSON 解析面板自动暂停刷新
- 重连成功后自动恢复，无需手动操作

### ⏯ 手动暂停 vs 自动暂停

- **断线时**：软件自动暂停面板刷新
- **手动暂停**：点击暂停按钮
- **优先级**：手动暂停优先 — 即使重连成功也不会自动恢复，防止打断你的数据查看

## 九、常见问题

**Q：数据不显示？**

A：请检查三项：
1. MQTT 是否已连接（看底部状态栏）
2. 设备 SN 是否正确（与实际设备一致）
3. Topic 是否已启用（显示为 ● 实心）

**Q：连接测试失败？**

A：提示"连接失败请检查配置参数是否有误"。确认 IP、端口、用户名、密码无误，且电脑能 ping 通 MQTT 服务器。

**Q：抓包文件在哪？**

A：保存在软件同目录下的 `captures/` 文件夹中。抓包停止后弹窗中有「打开文件夹」按钮可以直接跳转。

**Q：配置文件保存在哪？**

A：`config.json`，在软件同目录下。首次运行自动生成。

> ⚠️ 这个文件包含 MQTT 连接密码，请勿分享给他人或提交到公开仓库。

**Q：怎么同时监控多个设备？**

A：点「＋」重复添加即可。Dock 类型的设备下还可以添加多架手飞飞机。
