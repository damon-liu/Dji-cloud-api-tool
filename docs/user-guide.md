# DJI Cloud API 监控客户端 — 使用指南

> Qt 6 C++ 桌面应用 | MQTT 实时遥测 | 机场 & 无人机双视角监控

---

## 一、简介

**DJI-CLOUD-API 监控客户端**是一款基于 MQTT 协议的大疆机场/无人机实时遥测监控工具。

只需配置 MQTT Broker 连接参数并添加设备，即可实时接收并可视化展示机库 OSD 数据、飞机飞行状态、原始 JSON 报文，支持数据抓包导出、多 Profile 配置切换。

> 🔗 项目地址：https://github.com/damon-liu/Dji-cloud-api-tool

---

## 二、快速开始

### 2.1 下载与运行

从 [Releases](https://github.com/damon-liu/Dji-cloud-api-tool/releases) 下载最新版 `DjiCloudApi.exe`，双击运行即可。

首次启动会自动生成默认配置文件 `config.json`。

### 2.2 配置 MQTT 连接

点击工具栏 **⚙ 配置**，打开连接配置对话框：

```
┌──────────────────────────────────────┐
│  MQTT 连接配置                        │
│                                      │
│  Connections: [默认 ▾]  [+][✎][✕]   │
│  ──────────────────────────────────  │
│  Broker IP:  [192.168.1.100]         │
│  端口:       [8883]                  │
│  用户名:     [admin]                 │
│  密码:       [****]                  │
│                                      │
│       [Test]          [OK] [Cancel]  │
└──────────────────────────────────────┘
```

- 填写 MQTT Broker 的 IP、端口、用户名、密码
- 点击 **Test** 测试连接是否成功
- 点击 **OK** 保存配置

### 2.3 添加设备

在左侧 **Devices列表** 区域：

- 点击 **＋** 添加设备 → 选择设备类型（Dock机场 / Pilot手飞）
- 输入设备 SN 和名称
- 系统自动订阅默认 OSD Topic

> 💡 **提示**：添加机场设备时，系统会自动创建关联的子飞机设备。

## 四、核心功能

### 4.1 OSD 实时面板

> 1 秒刷新，间隔可调（1s / 2s / 5s / 10s）

**机场信息**（选中 Dock 设备时显示）：

| 字段 | 说明 |
|------|------|
| 经纬度 | 机库 GPS 坐标 |
| 舱盖 | 打开/关闭 |
| 飞行器 | 在舱内/已离舱 |
| 舱内温度 | 机库内部温度 |
| 环境温度 | 室外温度 |
| 风速 | 当前风速 |
| 降雨量 | 降雨量 |

**飞机信息**（与机场并排显示）：

| 字段 | 说明 |
|------|------|
| 飞行状态 | 待机/起飞/航线飞行/返航等 |
| 经纬度 | 飞机 GPS 坐标 |
| 电量 | 电池剩余百分比 |
| 电池温度 | 电池温度 |
| 高度 | 相对起飞点高度 |
| 距Home | 距起飞点距离 |
| 风速 | 当前风速 |
| GPS搜星 | GPS 卫星数量 |

> 🛡️ **防闪烁机制**：面板只在数据真正变化时刷新，无值字段保持上次有效值不变。

### 4.2 JSON 解析面板

将原始 JSON 数据按 topic 映射配置翻译为中文显示：

- 点击左侧 Topic 列表切换显示对应 topic 的解析数据
- 支持**暂停/继续**、**刷新间隔调整**
- 点击任意字段名 → 复制对应的 JSON key 到剪贴板

### 4.3 原始 JSON 面板

实时展示 MQTT 原始报文：

- 每条数据自动标注 **Topic** 和 **时间戳**
- **暂停/继续**：冻结界面刷新，数据持续订阅
- **复制**：复制全部 JSON 内容
- **清除**：清空历史记录

### 4.4 抓包导出

点击 **⬤ 抓包** → 选择保存路径 → 该 Topic 所有后续数据实时写入 `.json` 文件

- 文件命名：`{设备SN}-{topic类型}-{时间}.json`
- 格式：标准 JSON 数组，保留原始缩进
- 停止时弹窗显示路径，支持**一键跳转到文件夹**

## 五、设备管理

### 5.1 设备列表

- 每台设备显示：🟢/🔴 在线状态 + **名称-SN**
- **双击**设备 → 复制 SN 到剪贴板
- **右键**设备 → 重命名 / 复制 SN

### 5.2 Topic 管理

选中设备后，下方显示其订阅的 Topic 列表：

| 按钮 | 功能 |
|------|------|
| ⊘ | 全部启用/全部禁用（智能切换） |
| ◎ | 启用/禁用当前选中 Topic |
| ＋ | 新增 Topic |
| ✕ | 删除 Topic |
| ▲▼ | 调整 Topic 顺序 |

- ● 实心 = 已启用（订阅中）
- ○ 空心 = 已禁用（取消订阅）
- **双击** Topic → 复制完整 Topic 字符串

## 六、多 Profile 配置

支持多套 MQTT 连接配置，每套绑定独立的设备列表：

- 在配置对话框中切换 / 新增 / 重命名 / 删除 Profile
- 切换 Profile 时自动加载对应的设备列表
- 配置文件位于 `config.json`（首次运行自动生成，不会提交到代码仓库）

```json
{
  "current_profile": "生产环境",
  "profiles": [{
    "name": "生产环境",
    "mqtt": {"host": "192.168.1.100", "port": 8883, ...},
    "devices": [{"sn": "dock_001", "topics": [...]}]
  }]
}
```

## 七、进阶技巧

### 7.1 连接状态联动

- MQTT **断开**时：OSD 面板和 JSON 解析面板自动暂停刷新
- MQTT **重连**时：自动恢复刷新
- 手动暂停优先于自动恢复

### 7.2 快捷键

| 操作 | 方式 |
|------|------|
| 复制设备 SN | 双击设备行 |
| 复制 Topic | 双击 Topic 行 |
| 复制 JSON key | 点击解析面板字段名 |
| 重命名设备 | 右键设备 → 重命名 |

### 7.3 抓包文件格式

```json
[
{
  "tid": "f3a33071-...",
  "timestamp": 1781771950838,
  "data": {
    "latitude": 30.5001,
    "longitude": 114.5791,
    ...
  }
},
...
]
```

> 📁 抓包文件保存在程序目录下的 `captures/` 文件夹中。
