# 🚀 大疆上云调试利器 Dji-Cloud-Api-Tool v1.0.4 发布

> 专为 DJI Cloud API 设计的桌面调试工具，免安装绿色版，Windows 10/11 x64 直接运行。

---

v1.0.3 发布后，收获了不少开发者的关注和好评，也陆续收到一些实实在在的需求反馈：每次起飞都要手写 JSON 参数能不能可视化配置？视频直播什么时候不再是"敬请期待"？机场 PSDK 喊话器能不能直接在工具里调试？部分功能还有bug细节也需要优化。

**这一版，全都安排上了。**

v1.0.4 聚焦三个方向：**视频直播落地**（飞机/机场双窗口实时推拉流）、**PSDK 喊话器集成**（TTS + 音频播报全流程调试）、**一键起飞**。同时根对主窗口布局、Topic下发记录、机场控制面板、配置中心切换等细节进行了全面打磨。

于是，我们继续迭代了 **[Dji-Cloud-Api-Tool](https://gitee.com/damon123-liu/dji-cloud-api-tool)**，正式发布 v1.0.4。



## 🆕 v1.0.4 新增功能

- **🔊 PSDK 喊话器控制**：支持 TTS 文字播报和音频文件播报两种模式，音量调节、播报模式切换、停止/重播功能；

- **🖼️ 嵌入应用图标**：启动.exe 文件、任务栏处嵌入专属图标，增加工具辨识度；

- **🐛 Bug及细节优化**：主要功能默认集成到主窗口最上方一行、Topic下发列表移动至Topic订阅列表下方、简化设备添加默认名称、机场控制面板布局细化、 OSD 字段显示优化；配置中心连接切换底层Bug修复等；

## ✨ 核心功能

- **多环境一键切换**：支持多个 Connection 配置，生产/测试环境互不干扰
- **设备树形管理**：机场 + 无人机层级展示，在线状态实时指示，支持新增/删除/重命名
- **机场飞机自动订阅**：连接机场后自动识别并添加关联的无人机
- **设备 OSD 面板**：机场信息与飞机信息并排显示，刷新间隔可调，鼠标悬停显示字段 key、点击可复制
- **Topic 订阅管理**：每个设备独立管理 Topic，自动订阅大疆机场 7 个常用 Topic，支持新增/删除/启用/禁用/拖拽排序
- **上报JSON管理**：按设备 Topic 过滤报文，支持暂停滚动、一键复制、清除历史
- **上报JSON抓包导出**：一键抓包，数据实时写入 `captures/` 文件夹，停止后弹窗显示路径和记录条数
- **上报JSON 字段自动翻译**：根据大疆上云官网自动翻译 Topic 上报 json 参数 key，按分组展示，支持网格和列表分组查看
- **Topic 下发**：自动预设常用下发 Topic，每个 Topic 提供官方下发参数 JSON 模板
- **Topic 下发记录**：自动记录每次下发与响应，成功/失败一目了然
- **控制中心-机场控制**：集成远程调试、飞机电源、机场舱盖、飞机充电、机场维护、强制关舱门等快捷控制，实时显示发送及响应消息记录
- **控制中心-飞行控制**：支持飞行控制权限抢夺/释放、一键起飞（参数可配置）/返航/取消返航/紧急停机等飞行指令
- **控制中心-负载控制**：支持负载控制权限抢夺/释放、拍照/录像/云台回中等负载控制；支持多机场下拉切换
- **控制中心-PSDK 喊话器**：支持 TTS 文字转语音播报和音频文件 URL 播报，音量可调，播报模式可切换，实时进度管线展示
- **视频直播**：飞机/机场双窗口独立直播，支持镜头切换（红外/变焦/广角）、视频源切换（内外视频）、5档清晰度调节
- **自动重连**：指数退避（1s → 2s → … → 最长 30s），恢复后自动刷新
- **断线保护**：断线自动暂停面板刷新，手动暂停优先级更高，不打断数据查看



## 🆚 vs MQTTX

很多开发者使用 [MQTTX](https://mqttx.app/) 进行 MQTT 调试，但针对 DJI Cloud API 场景，本工具有以下明显优势：

| 对比维度 | MQTTX | DjiCloudApiTool |
|----------|-------|-----------------|
| 设备识别 | 只能看到 Topic 字符串，需人工判断是哪个设备 | 自动识别设备 SN，树形展示机场与子飞机的层级关系 |
| 设备管理 | 所有 Topic 混在一起，无层级结构 | 每个设备独立管理 Topic，支持启用/禁用/拖拽排序 |
| 自动关联子设备 | 无 | 机场添加以后发现并订阅子飞机 |
| 自动订阅Topic | 无（需手动逐个添加 Topic） | 添加机场自动订阅 7 个Topic |
| 上报JSON管理 | 无分类筛选能力 | 支持原始 JSON 实时滚动、暂停/恢复、一键复制、清除历史 |
| JSON抓包导出 | 需手动复制粘贴或配置外部工具 | 一键抓包，数据实时写入 `captures/` 文件夹，按设备/Topic 分类保存 |
| JSON自动翻译 | 原始 JSON，字段名全英文（如 `drone_in_dock`） | 自动翻译为中文，按分组展示，一目了然 |
| Topic 指令下发 | 手动输入 Topic 字符串 + 手写 JSON 参数 | 自动预设常用下发 Topic，每个 Topic 提供官方下发参数 JSON 模板 |
| Topic下发记录 | 需自行保存或外部记录 | 自动记录每次下发与响应，成功/失败一目了然 |
| 机场控制 | 需手动拼装指令 JSON | 点击按钮一键控制，进入远程调试后可用，实时反馈执行结果 |
| 飞行控制 | 需手动拼装指令 JSON | 独立飞行控制窗口，一键起飞/返航/降落 |
| 负载控制 | 需手动拼装指令 JSON | 独立飞行控制窗口，一键拍照/录像 |
| PSDK 喊话器 | 需手动拼装指令 JSON | 独立 PSDK 喊话器面板，可视化配置播报参数，实时进度管线展示 |
| 视频直播 | 无视频直播能力 | 飞机/机场双窗口独立直播，支持飞机多镜头、机场内外视频源切换、清晰度调节 |
| 环境依赖 | 需安装 Node.js 或下载桌面版 | 可执行文件 exe，无需任何依赖 |
| 学习成本 | 通用 MQTT 工具，需自行理解 DJI 协议 | 专为 DJI Cloud API 设计，开箱即用 |
| 行业定制 | 无 | 专门针对大疆上云定制版本，后续持续更新内容 |

> 💡 总结：MQTTX 是优秀的通用 MQTT 调试利器，但 DjiCloudApiTool 在 DJI 行业设备场景下效率更高——**设备层级树展示、自动关联订阅机场无人机、默认集成设备上下行的所有 Topic、Topic 抓包导出、JSON 自动翻译、Topic指令下发及下发记录、机场快捷控制、飞行控制、负载控制、PSDK 喊话器、视频直播**等功能都是针对大疆设备的专属优化。

## 🚶 三步上手

详细的使用指南请参照：https://github.com/damon-liu/Dji-cloud-api-tool/blob/main/docs/user-guide.md

### 1️⃣ 配置 MQTT
点击左上角 **「⚙ 配置」** → 填写 Broker IP / 端口 / 用户名 / 密码 → **「Test」** 测试 → **「OK」** 保存

### 2️⃣ 添加设备
点击左侧 **「＋」** → 选择 Dock（机场）或 Pilot（无人机）→ 输入设备 SN 和名称 → 确定

> 💡 添加机场时自动创建关联的无人机设备。连接机场后也会自动发现并添加下方无人机。

### 3️⃣ 开始监控与控制
点击右上角 **「● 连接」**，OSD 面板和 JSON 面板开始实时刷新。

**设备控制：** 点击工具栏 **「功能中心」** → 选择 **「机场控制」** / **「飞行控制」** / **「PSDK 喊话器」** / **「运维模式」** / **「视频直播」** → 进入远程调试后即可使用卡片式快捷控制。

**Topic 下发：** 点击右侧下方 **「▶ Topic 下发」** 展开面板 → 选择 Topic 自动填入参数模板 → 编辑 JSON → 点击 **「发送」**。

## 🔍 v1.0.4 功能详解

---

### 🔊 PSDK 喊话器 — 全新的负载控制能力

v1.0.4 最大的更新：功能中心新增 **「PSDK 喊话器」** 控制面板，覆盖大疆机场 PSDK 喊话器的完整调试场景。

**TTS 文字转语音播报：**
- 输入播报名称 + 播报文字内容 → 自动计算 MD5 → 一键下发
- 支持中文、英文、数字混合文字，自动显示字符数统计
- 适用于日常广播、应急通知等场景

**音频文件 URL 播报：**
- 输入播报名称 + 音频文件 URL + MD5 → 一键下发
- 适用 OGG/MP3/WAV 等格式（MP3 仅支持 DJI RC Plus 遥控器播放）
- 格式自动校验，非法格式即时提示

**播报控制：**
- 🎚️ 音量滑块 0-100 实时调节（带防抖，避免频繁下发）
- 🔄 单次/循环播报模式切换
- ⏹️ 停止播报 / 🔁 重播按钮即时响应

**📡 进度管线展示：**
- 命令下发后，实时追踪每个 step 的执行进度（-1 未开始 / 0-99% 进行中 / 100% 已完成）
- TTS 与音频播报各自独立追踪进管线
- 进度条可视化，执行状态一目了然

**🔀 多机场 + PSDK 负载索引：**
- 顶部下拉框切换目标机场
- PSDK 负载索引选择器，适配多负载挂载场景

---



### 🛫 一键起飞参数配置 — 起飞前不再手写 JSON

起飞按钮现在弹出配置对话框，可视化设置所有起飞参数：

- **目标点经纬度**：默认填充机场 OSD 上报的经纬度，可手动修改
- **目标点高度**：支持**相对起飞点高度**和**椭球高度（HAE）**两种模式切换
- **安全起飞高度**：默认 2.0m，可调
- **返航高度**：默认 30.0m，可调
- **安全确认复选框**：必须勾选才能点击确认起飞，防止误操作

---



### 📺 视频直播 — 从规划到落地

v1.0.3 搭好了 UI 框架，v1.0.4 补全了功能实现：

> ⚠️ **使用前提**：视频直播依赖流媒体服务，使用前需先在 **「⚙ 配置中心」→ 流媒体服务配置** 中填写 RTMP 推流/拉流地址。当前仅支持 RTMP 协议。

- **流媒体服务配置**：配置中心新增流媒体服务配置面板，支持填写 RTMP 推流地址和拉流地址，视频直播功能依赖此配置；当前仅支持 RTMP 协议推拉流
- **双窗口独立运行**：飞机和机场各开独立窗口，互不干扰
- **飞机窗口**：支持切换红外相机 / 变焦相机 / 广角相机
- **机场窗口**：支持切换机场外视频 / 机场内视频
- **5 档清晰度**：自适应 / 流畅 / 标清 / 高清 / 超清，实时切换
- **窗口生命周期**：关闭主程序时自动清理所有视频窗口，不残留进程

### 🐛 Bug 修复及细节优化

v1.0.4 除了新增功能外，还进行了大量细节打磨和 Bug 修复，提升整体使用体验。

**主窗口布局优化：**
- 主要功能入口（功能中心菜单项）默认集成到主窗口工具栏最上方一行，减少操作层级
- Topic 下发列表移动至 Topic 订阅列表正下方，相关操作聚合在一处，减少视线跳转
- 添加设备时简化默认名称（新增 Dock 默认为"机场"、Pilot 默认为"飞机"），减少手动输入

**机场控制面板布局细化：**
- 远程调试卡片重构，状态显示与进入/退出按钮同行，分隔线切割操作区
- 控制按钮（充电/电源/舱盖/维护）按功能分组为上下两行，布局更紧凑
- 按钮统一样式（边框、圆角、悬停高亮）

**OSD 字段显示优化：**

- 解析坐标时从原始 JSON payload 提取经纬度/高度的原始字符串，保留 OSD 上报的精确小数位数

**配置中心底层修复：**
- 修复新增/删除 Connection 配置时的内部状态不一致问题：新增后设备树不再残留旧数据，删除时正确清理缓存与 Topic 映射
- 新增 Profile 后自动切换到新 Profile，并正确初始化配置
- 移除下发命令 payload 中冗余的 `gateway` 字段，精简所有控制指令的 JSON 结构

### 📋 下发记录面板 — 所有交互一览无余

v1.0.4 为所有控制窗口统一设计了 **下发记录面板**，将每次 MQTT 指令交互（下发 + 响应）完整记录下来，方便调试追溯。

**覆盖范围：**

- **Topic 下发面板**：主窗口 Topic 下发的发送与响应记录
- **机场控制面板**：远程调试、充电、电源、舱盖、维护等指令的发送与响应
- **飞行控制面板**：飞行控制、负载控制的指令与响应，记录区域固定在底部
- **PSDK 喊话器面板**：TTS / 音频播报指令及进度回调记录
