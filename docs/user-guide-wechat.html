DJI Cloud API 监控客户端 — 用户使用指南


一、这是什么？


本工具通过 MQTT 协议连接 DJI Cloud API，实时接收并展示机场和无人机的Topic数据，主要用于日常对接调试大疆上云API（第三方机场如果提供类似大疆上云API也可使用），是大疆行业设备开发者和运维人员的必备调试工具。


1.1 核心功能


MQTT 连接管理：支持 SSL/TLS 加密连接，可配置 Broker 地址、端口、用户名和密码，连接状态实时显示在底部状态栏；


多环境配置切换 ： 支持多个 Connection（连接配置），每个 Connection 拥有独立的 MQTT 参数和设备列表，一键切换生产/测试环境，互不干扰；


设备树形管理 ：树形展示机场 + 无人机设备的层级关系，支持新增/删除/重命名设备，在线状态实时指示等


OSD 遥测面板 ： 机场数据和飞机数据实时刷新；


JSON 字段自动翻译 ： 将 DJI JSON 报文中的英文字段自动翻译为中文，字段意义一目了然；


原始 JSON 面板 ：按选中订阅 Topic 过滤 MQTT 原始报文，支持暂停滚动、一键复制全部内容和清除历史记录；


Topic 订阅管理 : 对每个设备独立管理 Topic 列表，支持新增/删除/启用/禁用/拖拽排序，添加机场时自动创建常用 Topic，省去手动配置 Topic 工作；抓包导出 — 将接收到的 MQTT 数据实时写入 captures/ 文件夹，支持随时开始/停止，停止后弹窗显示文件路径和记录条数；


自动重连 : MQTT 意外断开后指数退避自动重连（1s → 2s → 4s → 8s → 最长 30s），重连成功后自动恢复数据刷新；


刷新间隔可配 : OSD 面板和 JSON 解析面板刷新间隔均可独立调节（1s / 2s / 5s / 10s），适应不同网络环境和数据量；


断线保护 : 断开连接时自动暂停面板刷新，避免无效重绘；手动暂停优先级高于自动恢复，防止打断数据查看；


免安装绿色运行 : 下载即用，无需安装 Qt 或其他任何依赖，Windows 10/11 x64 直接运行；



1.2 对比 MQTTX 优点


很多开发者使用 MQTTX 进行 MQTT 调试，但针对 DJI Cloud API 场景，本工具有以下明显优势：


对比维度MQTTXDjiCloudApiTool
设备识别只能看到 Topic 字符串，需人工判断是哪个设备自动识别设备 SN，树形展示机场与子飞机的层级关系
数据可读性原始 JSON，字段名全英文（如 `cabin_opened`、`drone_in_dock`）自动翻译为中文，分组展示，一目了然
多设备管理所有 Topic 混在一起，无层级结构每个设备独立管理 Topic，支持启用/禁用/拖拽排序
抓包导出需手动复制粘贴或配置外部工具一键抓包，自动按设备和 Topic 分类保存到 `captures/` 文件夹
配置切换每次切换服务器需手动修改连接参数多 Connection 配置，一键切换生产/测试环境
断线处理需手动重连自动重连 + 指数退避，恢复后自动刷新数据
JSON 字段定位需在长 JSON 中肉眼查找字段点击翻译面板中的字段名直接复制原始 key，精准定位
环境依赖需安装 Node.js 或下载桌面版单文件 exe，无需任何依赖
学习成本通用 MQTT 工具，需自行理解 DJI 协议专为 DJI Cloud API 设计，开箱即用

💡 总结：MQTTX 是优秀的通用 MQTT 调试利器，但 DjiCloudApiTool 在 DJI 行业设备场景下效率更高——自动翻译、设备层级树、抓包导出、多环境一键切换等功能都是针对大疆设备的专属优化。

三、操作说明


3.1 连接 MQTT 服务器


打开软件后，先连上你的 MQTT Broker（这是数据来源），按如下操作：


① 点击左上角「⚙ 配置」按钮会弹出一个配置窗口：



② 填写Broker参数


参数说明示例
Broker IPMQTT 服务器地址127.0.0.1
端口一般是 88838883
用户名MQTT 用户名admin
密码MQTT 密码你的密码

③ 点「Test」测试连接


⚠️ 如果提示"连接失败请检查配置参数是否有误"，请确认 IP、端口、用户名、密码无误。




④ 测试通过后，点「OK」保存



3.2、添加设备


连上服务器后，需添加设备。



① 点击左侧「＋」按钮


② 选择设备类型


Dock (机场)：大疆机场/机库设备

Pilot (手飞飞机)：无人机


③ 输入设备 SN 和设备名称


④ 点击确定，左侧会显示设备列表：


🟢 绿色 = 设备在线

🔴 红色 = 设备离线


3.3 设备列表操作


操作方式
选中设备单击设备行
复制设备 SN双击设备行
重命名设备右键设备 → 重命名
添加子设备选中机场 → 点「＋」→ 为机场添加手飞无人机
删除设备选中设备 → 点「✕」


3.4 连接监控


点右上角 「● 连接」 按钮，软件开始接收数据，连接成功后：


1、状态栏显示「🟢 已连接」

2、右侧面板开始实时刷新数据

3、原始 JSON 窗口开始滚动显示报文

六、常见问题


🖥 运行相关


Q：下载 zip 包后双击 exe 没有运行按钮？



A：这是 Windows Defender 对陌生文件的正常拦截。点击「更多信息」→「仍要运行」即可。如果希望一劳永逸，将 exe 所在文件夹加入 Defender 排除列表。



📡 连接相关


Q：连接测试失败？


A：提示"连接失败请检查配置参数是否有误"。请依次确认：

Broker IP 和端口号是否正确

用户名和密码是否与 MQTT 服务器一致

电脑是否能 ping 通 MQTT 服务器（ping 服务器IP）


Q：数据不显示？


A：请检查三项：

MQTT 是否已连接（看底部状态栏是否为「🟢 已连接」）

设备 SN 是否正确（必须与实际设备序列号完全一致）

Topic 是否已启用（列表中显示为 ● 实心，而非 ○ 空心）



📁 文件相关


Q：抓包文件在哪？


A：保存在软件同目录下的 captures/ 文件夹中。抓包停止后弹窗中有「打开文件夹」按钮可直接跳转。文件命名规则：设备SN-topic类型-时间.json。


Q：配置文件保存在哪？


A：config.json，在软件同目录下，首次运行自动生成。


⚠️ 此文件包含 MQTT 连接密码，请勿分享给他人或提交到公开仓库。



🔧 使用相关


Q：怎么同时监控多个设备？


A：点「＋」重复添加即可。Dock（机场）设备下还可以添加多架子飞机。


Q：软件需要联网吗？


A：软件通过 MQTT 协议连接 DJI Cloud API Broker 获取实时数据，请确保电脑与 Broker 之间的网络畅通。
