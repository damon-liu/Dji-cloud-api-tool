# 🚀 DjiCloudApiTool v1.0.1 ：大疆上云API MQTT 桌面调试工具

> 专为 DJI Cloud API 设计的桌面调试工具，免安装绿色版，Windows 10/11 x64 直接运行。

---

## ✨ 核心功能

- **MQTT 连接管理** ：SSL/TLS 加密连接，连接状态实时显示
- **多环境一键切换** ：支持多个 Connection 配置，生产/测试环境互不干扰
- **设备树形管理** ：机场 + 无人机层级展示，在线状态实时指示，支持新增/删除/重命名
- **机场飞机自动订阅** ：连接机场后自动识别并添加关联的无人机
- **设备OSD 遥测面板** ：机场信息与飞机信息并排显示，刷新间隔可调（1s/2s/5s/10s）
- **Topic 订阅管理** ：每个设备独立管理 Topic，自动订阅大疆机场 7 个常用 Topic，支持新增/删除/启用/禁用/拖拽排序
- **原始 JSON ** ：按设备Topic 过滤报文，支持暂停滚动、一键复制、清除历史
- **Topic上报抓包导出** ：一键抓包，数据实时写入 `captures/` 文件夹，停止后弹窗显示路径和记录条数
- **JSON 字段自动翻译** ：根据大疆上云官网自动翻译Topic上报json参数key，按分组展示，上报参数一目了然
- **Topic 下发** ：预设常用下发 Topic（`property/set`、`services`、`events_reply`、`requests_reply`、`drc/down`、`status_reply`），自动匹配参数模板，支持 JSON 编辑、发送历史
- **自动重连** ：指数退避（1s → 2s → 4s → … → 最长 30s），恢复后自动刷新
- **断线保护** ：断线自动暂停面板刷新，手动暂停优先级更高，不打断数据查看

### 🆚 vs MQTTX

很多开发者使用 [MQTTX](https://mqttx.app/) 进行 MQTT 调试，但针对 DJI Cloud API 场景，本工具有以下明显优势：

| 对比维度 | MQTTX | DjiCloudApiTool |
|----------|-------|-----------------|
| 设备识别 | 只能看到 Topic 字符串，需人工判断是哪个设备 | 自动识别设备 SN，树形展示机场与子飞机的层级关系 |
| 设备管理 | 所有 Topic 混在一起，无层级结构 | 每个设备独立管理 Topic，支持启用/禁用/拖拽排序 |
| 自动订阅 | 需手动逐个添加 Topic | 添加机场自动订阅 7 个常用 Topic，连接后自动发现并订阅子飞机 |
| 数据可读性 | 原始 JSON，字段名全英文（如 `cabin_opened`、`drone_in_dock`） | 自动翻译为中文，按分组展示，一目了然 |
| Topic 下发 | 手动输入 Topic 字符串 + 手写 JSON 参数 | 预设 6 个常用下发 Topic，自动匹配参数模板一键填入，发送历史双击恢复 |
| 抓包导出 | 需手动复制粘贴或配置外部工具 | 一键抓包，数据实时写入 `captures/` 文件夹，按设备/Topic 分类保存 |
| 配置切换 | 每次切换服务器需手动修改连接参数 | 多 Connection 配置，一键切换生产/测试环境 |
| 断线处理 | 需手动重连 | 自动重连 + 指数退避（1s→2s→4s→…→30s），恢复后自动刷新数据 |
| JSON 字段定位 | 需在长 JSON 中肉眼查找字段 | 点击翻译面板中的字段名直接复制原始 key，精准定位 |
| 环境依赖 | 需安装 Node.js 或下载桌面版 | 单文件 exe，无需任何依赖 |
| 学习成本 | 通用 MQTT 工具，需自行理解 DJI 协议 | 专为 DJI Cloud API 设计，开箱即用 |

> 💡 总结：MQTTX 是优秀的通用 MQTT 调试利器，但 DjiCloudApiTool 在 DJI 行业设备场景下效率更高——**设备层级树展示、自动关联订阅机场无人机、Topic 下发模板一键填入、抓包导出、JSON 自动翻译**等功能都是针对大疆设备的专属优化。

## 🚶 三步上手

### 1️⃣ 配置 MQTT
点击左上角 **「⚙ 配置」** → 填写 Broker IP / 端口 / 用户名 / 密码 → **「Test」** 测试 → **「OK」** 保存

### 2️⃣ 添加设备
点击左侧 **「＋」** → 选择 Dock（机场）或 Pilot（无人机）→ 输入设备 SN 和名称 → 确定

> 💡 添加机场时自动创建关联的无人机设备。连接机场后也会自动发现并添加下方无人机。

### 3️⃣ 开始监控与下发
点击右上角 **「● 连接」**，OSD 面板和 JSON 面板开始实时刷新。

**Topic 下发：** 点击右侧下方 **「▶ Topic 下发」** 展开面板 → 选择 Topic 自动填入参数模板 → 编辑 JSON → 点击 **「发送」**。
