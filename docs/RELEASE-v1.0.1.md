# 🚀 DjiCloudApiTool v1.0.1 — 大疆上云API MQTT 桌面调试工具

> 专为 DJI Cloud API 设计的桌面调试工具，免安装绿色版，Windows 10/11 x64 直接运行。

---

## 🆕 v1.0.1 新增功能

- **Topic 下发** — 预设常用下发 Topic，自动从 `topic-send-construct.md` 匹配参数模板，支持 JSON 编辑、发送历史（双击恢复）
- **机场飞机自动发现** — 连接机场后自动识别并添加关联的无人机（从机场 OSD 中提取）
- **Topic 列表可拖拽** — 左侧面板设备树与 Topic 列表之间支持拖拽调整高度
- **连接后自动选中设备** — 连接成功后自动选中第一个设备，OSD 面板即刻刷新
- **修复 Connection 切换** — 配置页面切换 Connections 时立即生效
- **帮助按钮** — 工具栏新增帮助按钮，快速跳转到使用指南

## ✨ 核心功能

- **MQTT 连接管理** — SSL/TLS 加密连接，连接状态实时显示
- **多环境一键切换** — 支持多个 Connection 配置，生产/测试环境互不干扰
- **设备树形管理** — 机场 + 无人机层级展示，在线状态实时指示，支持新增/删除/重命名
- **机场飞机自动发现** — 连接机场后自动识别并添加关联的无人机
- **OSD 遥测面板** — 机场信息与飞机信息并排显示，刷新间隔可调（1s/2s/5s/10s）
- **JSON 字段自动翻译** — 英文字段自动翻译为中文，按分组展示，点击字段名即可复制原始 key
- **原始 JSON 面板** — 按 Topic 过滤报文，支持暂停滚动、一键复制、清除历史
- **Topic 订阅管理** — 每个设备独立管理 Topic，支持新增/删除/启用/禁用/拖拽排序；添加机场自动创建 7 个常用 Topic
- **Topic 下发** — 预设常用下发 Topic（`property/set`、`services`、`events_reply`、`requests_reply`、`drc/down`、`status_reply`），自动匹配参数模板，支持 JSON 编辑、发送历史、双击恢复
- **📦 抓包导出** — 一键抓包，数据实时写入 `captures/` 文件夹，停止后弹窗显示路径和记录条数
- **自动重连** — 指数退避（1s → 2s → 4s → … → 最长 30s），恢复后自动刷新
- **断线保护** — 断线自动暂停面板刷新，手动暂停优先级更高，不打断数据查看

### 🆚 vs MQTTX

| 对比维度 | MQTTX | DjiCloudApiTool |
|----------|-------|-----------------|
| 设备识别 | 看 Topic 字符串人工判断 | 自动识别 SN，树形展示层级关系 |
| 数据可读性 | 全英文原始 JSON | 自动翻译中文，分组展示 |
| Topic 下发 | 手动输入 Topic + JSON | 预设模板，自动匹配参数，一键填入 |
| 抓包导出 | 手动复制或外部工具 | 一键抓包，按设备/Topic 分类保存 |
| 环境依赖 | 需安装 Node.js | 单文件 exe，零依赖 |

## 🚶 三步上手

### 1️⃣ 配置 MQTT
点击左上角 **「⚙ 配置」** → 填写 Broker IP / 端口 / 用户名 / 密码 → **「Test」** 测试 → **「OK」** 保存

### 2️⃣ 添加设备
点击左侧 **「＋」** → 选择 Dock（机场）或 Pilot（无人机）→ 输入设备 SN 和名称 → 确定

> 💡 添加机场时自动创建关联的无人机设备。连接机场后也会自动发现并添加下方无人机。

### 3️⃣ 开始监控与下发
点击右上角 **「● 连接」**，OSD 面板和 JSON 面板开始实时刷新。

**Topic 下发：** 点击右侧下方 **「▶ Topic 下发」** 展开面板 → 选择 Topic 自动填入参数模板 → 编辑 JSON → 点击 **「发送」**。
