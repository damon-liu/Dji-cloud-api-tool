🔄 数据流

用户选中设备+Topic 后的刷新流程
1. 用户点击 Topic 列表中的某个 topic
2. TopicListWidget::topicSelectionChanged 信号发出
3. OsdParsePanel::setTopic(sn, topic) 被调用
4. TopicMapping::mappingForTopic(topic) 查找对应的映射表
5. QTimer (默认 2s) 触发 → refresh()
6. 从 DeviceManager::latestRawJson(sn) 获取最新 JSON
7. 解析 JSON → 用映射表翻译 key → 按分组渲染
8. 值变化时高亮闪烁 (复用 OsdPanel 模式)
