JSON 解析面板 — 布局位置选择

PRD 1.4：「设备信息下面新增一个JSON解析独立的区域」— 新面板应该放在哪里？

A

方案 A：OSD 面板下方垂直堆叠

在右侧水平分割器的左半区，OSD面板下方新增解析面板。
与原始JSON左右并排，保持现有布局结构不变。

B

方案 B：原始JSON下方新增

在右侧水平分割器的右半区（原始JSON下方）新增解析面板。
JSON数据在上，翻译解析在下，逻辑关联更紧密。

C

方案 C：三区纵向排列

取消水平分割，改为三个区域垂直排列：设备信息 → JSON解析 → 原始JSON。
阅读顺序从上到下，信息密度更高。
