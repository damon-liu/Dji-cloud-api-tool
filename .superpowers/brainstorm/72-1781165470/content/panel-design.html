JSON 解析面板 — UI 设计

面板放在设备信息下方，定时从右侧原始 JSON 获取最新数据进行翻译展示

选择展示风格

A

方案 A：分组表格

按类别分组（电量/位置/飞行状态/环境），每组一个 section，用 QFormLayout 风格展示。
直观清晰，适合快速查找。

B

方案 B：扁平列表

所有字段一个列表，按 JSON 中出现的顺序排列。中文名在前，值在后。
简单直接，但字段多了不易浏览。

C

方案 C：JSON 树

保持原始 JSON 的嵌套结构，但将 key 替换为中文。
结构保真，但 UI 实现复杂，嵌套层级多时体验差。

交互细节说明

⏱ 定时刷新逻辑

  • 使用 QTimer，默认间隔 2 秒（匹配 OSD 0.5Hz 上报频率）
  • 间隔可通过 spinbox 调整 (1s / 2s / 5s / 10s)
  • 只取 最新一条 JSON 数据解析
  • 暂停按钮只暂停面板刷新，不影响后台数据订阅
  • 恢复时立即用最新数据刷新

✨ 值变化高亮

  • 新旧值对比，变化的值短暂高亮（蓝色闪烁 1.2s）
  • 复用 OsdPanel 的 setFieldValue 高亮模式
  • 无变化的值静默更新，不分散注意力
  • 未映射字段默认灰色显示，低调处理
